# Piano — браузерная ритм-игра

Самостоятельная версия по ТЗ: без Telegram, регистрации и backend.

## Запуск

Самый простой вариант — открыть папку через локальный HTTP-сервер.

### VS Code
Установить расширение Live Server и открыть `index.html`.

### Python
В каталоге проекта:

```bash
python -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Файлы

- `index.html` — страницы и UI.
- `styles.css` — адаптивный интерфейс.
- `app.js` — игровой цикл, Canvas и управление.
- `game.js` — чистые правила попаданий и расчётов.
- `data.js` — 5 мелодий и карты.
- `audio.js` — Web Audio.
- `storage.js` — локальные рекорды и mute.

## Управление

ПК: `D F J K`, `Esc`.

Телефон: нажатие на одну из четырёх видимых дорожек. Длинные плитки нужно удерживать.

## Правила

- Perfect: до ±90 мс.
- Отлично: до ±180 мс.
- Есть: до ±280 мс.
- Базовые очки: 100 / 80 / 50.
- Каждые 10 успешных плиток множитель увеличивается, максимум ×8.
- 3 ошибки заканчивают партию.
- После полного первого круга начинается следующий круг с новой раскладкой и большей скоростью.
- Максимальная скорость — 1.55×.
- Рекорды локальные, в `localStorage`.

## Ограничение

Музыка генерируется Web Audio. Игра должна оставаться доступной без звука.

## Проверка

Перед публикацией нужно дополнительно проверить Chrome/Edge на ПК и актуальные Chrome/Safari на телефоне, особенно сенсорное удержание, потерю фокуса, localStorage и звук.
